# Эшелон на Самарканд — AI-чат

Чат с героями романа Гузель Яхиной. Работает через YandexGPT.

## Как запустить локально

1. Распакуй архив
2. В терминале:
   ```bash
   cd tilda-ai-chat
   npm install
   npm run dev
   ```
3. Открой http://localhost:3000/chat

## Важно про ключи

Файл `.env.local` уже лежит в проекте с твоими ключами.

Если на Amvera — добавь переменные вручную в панели:
- `YANDEX_API_KEY`
- `YANDEX_FOLDER_ID`

## Что исправлено

- Убраны шаблонные ответы
- Теперь всегда идёт запрос в YandexGPT
- При ошибках видно точную причину (нет ключей / ошибка API / и т.д.)
